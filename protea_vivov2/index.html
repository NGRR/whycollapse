Protea Vive v16 / UI editorial

Una pagina que deja respirar el sistema.

La version v2 simplifica la muestra UI: despues del hero, el organismo de Protea Vive queda fijo como campo visual en el primer tercio de la pantalla, y cada seccion reduce su contenido a kick, titulo y parrafo.

Despues del hero

El fondo vivo entra como presencia fija, no como decoracion.

El canvas aparece al comenzar el tramo editorial y ocupa el primer tercio de la pagina. La zona derecha queda libre para leer, contrastar y decidir como reinsertar luego los componentes guardados.

01 / Fundamentos

Base visual

El azul sostiene el tono vivo de Protea.

El fondo adopta el azul de la protea viva para que la interfaz se lea dentro del mismo mundo visual: intenso, biologico y de alto contraste.

02 / Altos contrastes

Panel blanco

Las superficies blancas muestran decision y lectura.

Los paneles claros sirven para probar textos densos, estados y futuros modulos UIkit sin diluir la energia del fondo azul ni forzar componentes prematuros.

03 / Layout

Primer tercio

La izquierda queda fija para el organismo.

El recorrido reserva el primer tercio al canvas v16 y desplaza el texto hacia una columna amplia. La pagina se entiende como sistema antes que como catalogo.

04 / Navegacion

Sin saltos

Los marcadores ya no compiten con la lectura.

La navegacion interna se vuelve informativa y evita clicks que generen enlaces falsos o scroll accidental. Solo queda activa la salida al indice principal.

05 / Formularios

Pausa

Los controles volveran como momentos puntuales.

Inputs, selects, upload y validaciones quedaron preservados en assets para entrar despues como pequenas interrupciones utiles, no como una grilla permanente.

06 / Datos

Evidencia

La informacion estructurada necesita blanco.

Tablas, listas, comentarios y metricas se leen mejor sobre una superficie clara. La alternancia permite medir como conviven datos y organismo vivo.

07 / Media

Imagen

Los medios entran cuando aportan evidencia.

Sliders, overlays y lightbox se guardan para volver como pruebas visuales especificas. En esta version, la imagen dominante es el propio crecimiento de la protea.

08 / Estados

Feedback

Los estados aparecen solo cuando algo cambia.

Alertas, progreso, acordeones y empty states se reincorporaran despues donde el relato los necesite. Por ahora quedan disponibles como fragmentos limpios.

Assets saneados

Las secciones completas quedaron separadas para reinsertarlas.

La version anterior del kit conserva sus fragmentos en protea_vivo/uikit-protea/assets/sections/. Esta v2 usa solo la estructura editorial nueva.
